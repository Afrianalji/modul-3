# Sistem Manajemen Perpustakaan

Aplikasi konsol manajemen perpustakaan sederhana yang disusun untuk memenuhi tugas Modul 3 Praktikum Pemrograman Lanjut.

## 📌 Fitur Utama
- **Pengelolaan Koleksi**: Menambahkan dan menyimpan daftar buku.
- **Pencarian Buku**: Fitur pencarian buku berdasarkan kata kunci judul.
- **Kalkulator Denda**: Menghitung total denda keterlambatan pengembalian buku.
- **Dokumentasi JavaDoc**: Seluruh kelas dan method telah dilengkapi penjelasan berstandar JavaDoc.

## 🛠️ Prasyarat
- **Java Development Kit (JDK)**: Versi 11 atau lebih baru
- **Editor**: Visual Studio Code / IntelliJ IDEA

## 🚀 Cara Menjalankan Program

1. Buka terminal di dalam folder proyek, lalu kompilasi file Java:
   ```bash
   javac Perpustakaan.java
   ```

2. Jalankan aplikasi:
   ```bash
   java Perpustakaan
   ```

3. Generate dokumentasi HTML JavaDoc:
   ```bash
   javadoc -d docs Perpustakaan.java
   ```
